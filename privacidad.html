2. Qué datos recoge actualmente la web

La versión actual no incorpora un formulario de registro, boletín ni cuenta de usuario. Las herramientas “Test” y “Plan de hogar” utilizan almacenamiento local del navegador para recordar información en el propio dispositivo. Los datos introducidos en esas herramientas no se envían a Preparación Práctica mediante el código actual del sitio.

La infraestructura web puede procesar datos técnicos de las solicitudes necesarias para prestar, proteger y mantener el servicio. El proveedor de infraestructura es Cloudflare; el tratamiento concreto depende de los servicios configurados y de sus condiciones vigentes.

3. Finalidades

Cuando exista tratamiento de datos, las finalidades serán las estrictamente necesarias para prestar la funcionalidad solicitada, atender consultas o mantener y proteger el servicio. No se utilizarán datos obtenidos mediante formularios para fines distintos de los informados.

4. Base jurídica

La base jurídica se determinará según el tratamiento concreto: ejecución de una solicitud del usuario, consentimiento cuando sea necesario, obligación legal o interés legítimo cuando proceda y esté justificado.

5. Conservación y destinatarios

Los plazos de conservación y los destinatarios concretos deberán actualizarse cuando se active un formulario, analítica, boletín, sistema de afiliación u otro servicio que implique tratamientos adicionales.

6. Derechos

Las personas interesadas podrán solicitar, según corresponda, acceso, rectificación, supresión, oposición, limitación y portabilidad, así como retirar un consentimiento previamente prestado cuando la base sea el consentimiento.

La AEPD recomienda presentar la información por capas: una información básica en el momento de recoger los datos y otra detallada accesible de forma sencilla.

7. Autoridad de control

La autoridad española de control en materia de protección de datos es la Agencia Española de Protección de Datos (AEPD), ante la que puede presentarse una reclamación cuando proceda.
