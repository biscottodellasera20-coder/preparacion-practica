# Checklist antes de empezar a cobrar

[ ] Amazon: Store ID `preparacionpr-21` confirmado.
[ ] Amazon: beneficiario y cuenta bancaria correctos.
[ ] Amazon: revisar “Ver/Proporcionar información fiscal” si aparece.
[ ] Awin: cuenta publisher aprobada.
[ ] Decathlon ES: comprobar aprobación.
[ ] Aviso de afiliación visible en páginas con enlaces.
[ ] Datos del titular completados en Aviso legal/Privacidad/Contacto antes del lanzamiento comercial.
[ ] Revisar compatibilidad de actividad privada por tratarse de empleo público, antes de iniciar de forma efectiva la actividad lucrativa.
[ ] Mantener precios/stock fuera de texto fijo salvo fuente/feed actualizado.
[ ] Registrar comisiones y documentación contable desde el primer ingreso.
